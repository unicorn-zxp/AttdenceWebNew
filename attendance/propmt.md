# Role
你是一位资深的 Python 数据分析专家和全栈开发工程师。你擅长使用 Pandas 处理复杂的工程考勤逻辑，并能使用 Streamlit 快速构建具备专业数据统计功能的 Web 应用。

# Task
开发一个“工地考勤工资自动计算及可视化分析系统”。系统需要处理跨月/跨文件的考勤数据，并能够**严格按照用户提供的空白模板格式**生成最终的 Excel 报表。

# Data Definition
1. **表A（考勤表）：** 多文件/多Sheet，包含姓名、工号、日期、打卡时间。
2. **表B（员工花名册）：** 多Sheet，包含姓名、工号、工种。需全表合并并全局去重。
3. **表C（工资标准表）：** 包含工种、日薪标准（8h计）、加班时薪。
4. **输出模板：** 用户会提供一个“空白模板.xlsx”，系统生成的工资会报表必须保留模板的表头和格式。

# Business Logic
### 1. 人员过滤
* **排除工种：** 属于 **“管理”、“安全员”、“资料员”、“技术员”** 的人员不计考勤、不计工资。
* **异常判定：** 每日仅有一次打卡记录的视为异常，不计入报表。

### 2. 计算层级
* **汇总表逻辑 (Raw Data)：** - (每日最晚打卡 - 每日最早打卡) - 1h午休。
  - **不做修正、不做取整**，保留实际小数（如 10.78），代表真实工作时长。
* **工资表逻辑 (Settle Data)：**
  - **弹性进位：** - 早上：打卡 ≤ 07:40，按 07:30 计。
    - 晚上：距离下一个整点或半点 ≤ 10min，则补齐（如 19:22 补至 19:30，19:51 补至 20:00）。
  - **结算取整：** (补偿后时长 - 1h) 后，执行 **整小时向下取整**（如 11.9h 变 11h）。
  - **分配：** 取整结果中 ≤ 8h 为基本工时，> 8h 为加班工时。

# Frontend & Analysis (Streamlit)
1. **文件上传：** 增加“上传空白模板”入口。
2. **看板功能：** - 统计各工种的：总人数、总结算工时、总工资支出。
   - 占比分析：工资总额占比饼图、工时贡献占比饼图。
   - 趋势统计：按天/按月展示工地人力成本趋势。
3. **模板填充：** 使用 `openpyxl` 或 `xlsxwriter` 将计算结果填入用户提供的模板中，确保不破坏原有的单元格样式。

# Technical Requirements
- Python 3, Pandas, Streamlit, Plotly, Openpyxl。
- 代码需具备极强的鲁棒性，能够自动识别“姓名”或“工号”作为主键进行关联。
