## 输入文件格式

### 1. 花名册

- **文件**: `创新智成-西安东站-花名册-2026.4.xlsx`
- **目标 Sheet**: `创新智成 (班组花名册)  `（注意末尾可能有空格，代码自动处理）
- **Header 位置**: Row 2（openpyxl 1-indexed）
- **数据起始**: Row 3

| 列号 | 字段 | 说明 |
|------|------|------|
| Col A (1) | 序号 | 数字 |
| Col B (2) | 班组 | 始终为空 |
| Col C (3) | 姓名 | 用于考勤匹配的主键 |
| Col D (4) | 身份证号码 | 18位字符串 |
| Col E (5) | 性别 | 男/女 |
| Col F (6) | 工种 | 木工/瓦工/焊工/油工/普工等 |
| Col G (7) | 电话号码 | 手机号 |
| Col H (8) | 身份证地址 | 文本 |
| Col I (9) | **工日工资** | 数字（元/天），也可能为"15000元/月" |
| Col J (10) | **工时工资** | 数字（元/小时） |
| Col K (11) | 银行卡号 | |
| Col L (12) | 开户行名称 | |
| Col M (13) | 银行地址 | |
| Col N (14) | 进场时间 | 日期 |
| Col O (15) | 离场时间 | 日期 |
| Col P (16) | 合同编号 | 文本 |
| Col Q (17) | 备注 | 文本 |

### 2. 考勤文件（员工刷卡记录表）

- **文件**: `员工刷卡记录表.xls` / `.xlsx`，支持多个文件
- **内部格式**（无表头，逐行解析）：

```
Row 0: 员 工 刷 卡 记 录 表                              （标题，跳过）
Row 1: （空行）
Row 2: 考勤日期：2026-03-11～2026-04-10                   （日期范围）
Row 3: 制表时间：2026-04-11 07:34:16
Row 4: 工号：  1      姓名： 胡川云    部门： 智成         （员工标记行）
Row 5: 11  12  13  14  15  16  17  18  ...  1  2  3  4   （日期行，数字1-31）
Row 6: 06:41  06:44  ...                                  （打卡时间，可能多行）
Row 7: （空行 或 下一员工标记行）
```

打卡时间格式：`HH:MM`，同一格多个时间以换行符 `\n` 分隔。

### 3. 工资台账

- **文件**: `工资台账2026（超）.xlsx`
- **要求**: 包含一个含"工资表"关键字的 Sheet 作为模板（如 `2月11日-3月10日工资表`）
- **要求**: 包含 `年度工资汇总台账` Sheet

## 核心模块 API

### 1. `parse_xdz_roster`

```python
def parse_xdz_roster(file_path: str) -> Dict[str, dict]
```

**功能**: 解析创新智成-西安东站花名册，提取每个员工的个人信息和工资标准。

**输入**:
| 参数 | 类型 | 说明 |
|------|------|------|
| `file_path` | `str` | 花名册 Excel 文件路径 |

**输出**: `Dict[str, dict]`，以姓名为 key 的字典：
```python
{
    "张传山": {
        "工种": "木工",
        "工日工资": 300.0,        # float 或 None
        "工时工资": 50.0,         # float 或 None
        "备注": "",                # 空字符串 或 异常说明
        "性别": "男",
        "身份证号码": "37092119660122183X",
        "电话号码": "15501136728",
        "身份证地址": "山东省宁阳县磁窑镇枣庄村校门街99号",
        "合同编号": "",
    },
    ...
}
```

**特殊值处理**:
- `工日工资` 为 `"15000元/月"` → `工日工资=None`，`备注="月薪制(15000元/月)，需人工核算"`
- `工日工资` 为 `0` → 保留为 `0.0`，后续在计算时标记为"工日工资为0"
- `电话号码` 为数字类型 → 自动转为字符串（去掉 `.0`）

### 3. 工时计算引擎

#### `apply_early_rounding`

```python
def apply_early_rounding(punch_time: time, work_start: time = DEFAULT_WORK_START) -> time
```

早班弹性进位：打卡时间 ≤ `work_start + 10min` 时按 `work_start` 计算；早于 `work_start` 的也进位到 `work_start`（早到不算工时）。

#### `apply_late_rounding`

```python
def apply_late_rounding(punch_time: time, tolerance: int = 5) -> time
```

晚班弹性补齐：距整点或半点 ≤ `tolerance` 分钟时，向上补齐。

| 原始时间 | 容差5min | 补齐后 |
|----------|----------|--------|
| 17:27 | ≤5min到17:30 | 17:30 |
| 17:58 | ≤5min到18:00 | 18:00 |
| 17:35 | 不满足 | 17:35 |

#### `calculate_work_hours`

```python
def calculate_work_hours(
    times: List[time],
    work_start: time = DEFAULT_WORK_START,
    work_end: time = DEFAULT_WORK_END,
    break_start: time = DEFAULT_BREAK_START,
    break_end: time = DEFAULT_BREAK_END,
    tolerance: int = DEFAULT_LATE_TOLERANCE,
    for_settlement: bool = False
) -> Tuple[float, float, bool]
```

**功能**: 计算每日下班前工时和下班后工时。

**输入**:
| 参数 | 类型 | 说明 |
|------|------|------|
| `times` | `List[time]` | 当天所有打卡时间 |
| `work_start` | `time` | 上班时间，默认 07:30 |
| `work_end` | `time` | 下班时间，默认 17:30 |
| `break_start` | `time` | 休息开始时间，默认 12:00 |
| `break_end` | `time` | 休息结束时间，默认 13:00 |
| `tolerance` | `int` | 晚班弹性容差（分钟） |
| `for_settlement` | `bool` | 是否为结算模式（应用弹性进位和取整） |

**输出**: `(下班前工时, 下班后工时, 是否异常)`

**计算逻辑**:
1. 少于2次打卡 → 返回 `(0, 0, True)` 异常
2. 取最早和最晚打卡时间
3. 结算模式下应用 `apply_early_rounding` 和 `apply_late_rounding`
4. 早于 `work_start` 的打卡进位到 `work_start`（早到不算工时）
5. **下班前工时** = `work_end - 有效上班`，扣除休息重叠（仅当打卡区间实际经过休息窗口时扣除）
6. **下班后工时** = `max(0, 最晚打卡 - work_end)`
7. 结算模式下按半小时向下取整：`int(hours * 2) / 2`

**计算示例**（默认配置 07:30-17:30，休息12:00-13:00，额定9h）:
| 上班 | 下班 | 下班前 | 下班后 | 总工时 | 说明 |
|------|------|--------|--------|--------|------|
| 07:30 | 17:30 | 9.0 | 0.0 | 9.0 | 标准全天 |
| 07:30 | 19:30 | 9.0 | 2.0 | 11.0 | 加班2h |
| 13:00 | 23:00 | 4.5 | 5.5 | 10.0 | 下午班（无休息扣除） |
| 09:00 | 17:30 | 7.5 | 0.0 | 7.5 | 迟到（无午休扣除） |
| 05:30 | 17:30 | 9.0 | 0.0 | 9.0 | 早到进位到07:30 |

### 4. `process_xdz_data`

```python
def process_xdz_data(
    attendance_df: pd.DataFrame,
    roster_dict: Dict[str, dict],
    work_start: time = DEFAULT_WORK_START,
    work_end: time = DEFAULT_WORK_END,
    break_start: time = DEFAULT_BREAK_START,
    break_end: time = DEFAULT_BREAK_END,
    late_tolerance: int = DEFAULT_LATE_TOLERANCE,
) -> Tuple[pd.DataFrame, pd.DataFrame]
```

**功能**: 按花名册中的个人工资标准计算工资，处理异常情况。

**输入**:
| 参数 | 类型 | 说明 |
|------|------|------|
| `attendance_df` | `DataFrame` | `parse_attendance` 的输出 |
| `roster_dict` | `Dict[str, dict]` | `parse_xdz_roster` 的输出 |
| `work_start` | `time` | 上班时间，默认 07:30 |
| `work_end` | `time` | 下班时间，默认 17:30 |
| `break_start` | `time` | 休息开始时间，默认 12:00 |
| `break_end` | `time` | 休息结束时间，默认 13:00 |
| `late_tolerance` | `int` | 晚班弹性容差（分钟），默认 10 |

**输出**: `(salary_df, daily_df)`

#### salary_df（工资汇总表）

| 列名 | 类型 | 说明 |
|------|------|------|
| `序号` | `int` | 从1开始编号 |
| `姓名` | `str` | 员工姓名 |
| `工种` | `str` | 从花名册获取，未找到则"未知" |
| `出勤工日` | `int` | 有效出勤天数（排除单次打卡的异常天） |
| `日工资` | `float` | 花名册中的工日工资 |
| `加班工时` | `float` | 总加班小时数 |
| `加班工资` | `float` | 花名册中的工时工资（用于台账列显示） |
| `工资总额` | `float` | `(基本工时/8 × 工日工资) + (加班工时 × 工时工资)` |
| `未支付数` | `float` | 同工资总额（预支费等后续手工填写） |
| `备注` | `str` | 异常说明，正常为空字符串 |

#### daily_df（每日考勤明细）

| 列名 | 类型 | 说明 |
|------|------|------|
| `日期` | `int` | 1-31 |
| `姓名` | `str` | 员工姓名 |
| `工种` | `str` | 工种 |
| `上班打卡时间` | `time` | 当天最早打卡 |
| `下班打卡时间` | `time` | 当天最晚打卡 |
| `当日工时` | `float` | 基本工时 + 加班工时 |
| `基本工时` | `float` | 下班前工时（扣休息重叠） |
| `加班工时` | `float` | 下班后工时 |
| `当日基本工资` | `float` | `(D+R)/H × min(下班前, H)` |
| `当日加班工资` | `float` | `R × (max(下班前-H, 0) + 下班后)` |
| `当日总工资` | `float` | 基本工资 + 加班工资 |
| `备注` | `str` | 异常说明（如"包含多次打卡:06:50, 12:00, 17:30"） |

**工资计算公式**（D=工日工资, R=工时工资, H=额定工时）:
```
额定内工时 = min(下班前工时, H)
额外工时   = max(0, 下班前工时 - H) + 下班后工时

当日基本工资 = (D + R) / H × 额定内工时
当日加班工资 = R × 额外工时
当日总工资   = 当日基本工资 + 当日加班工资
```

**计算示例**（D=350, R=50, H=9）:
| 场景 | 下班前 | 下班后 | 工资计算 | 总工资 |
|------|--------|--------|----------|--------|
| 标准全天 07:30-17:30 | 9.0h | 0h | 400/9×9 | 400.0 |
| 加班 07:30-19:30 | 9.0h | 2.0h | 400+50×2 | 500.0 |
| 下午班 13:00-23:00 | 4.5h | 5.5h | 400/9×4.5+50×5.5 | 475.0 |
| 早到 05:30-17:30 | 9.0h | 0h | 400/9×9（进位到07:30） | 400.0 |
| 迟到 09:00-17:30 | 7.5h | 0h | 400/9×7.5 | 333.3 |

**只有满足以下全部条件才计算工资**（否则各工资列为0）:
- 花名册中存在此人
- `工日工资` 不为 None 且 > 0
- `工时工资` 不为 None
- `备注` 为空（无月薪制等异常标记）

### 7. `generate_ledger_sheet`

```python
def generate_ledger_sheet(
```

| `sheet_name` | `str` | 新 Sheet 名称，如 `"3月11日-4月10日工资表"` |
| `start_date` | `tuple` | `(年, 月, 日)` |
| `end_date` | `tuple` | `(年, 月, 日)` |

**生成的新 Sheet 结构**（18列，复制自模板 Sheet 的格式）:

| Row | 内容 |

| I (9) | 路费 | 留空 |

| L (12) | 罚款 | 留空 |
| M (13) | 其它 | 留空 |
| N (14) | 项目部代付 | 留空 |
| O (15) | 吴超付 | 留空 |
| P (16) | 未支付数 | salary_df['未支付数']（>0时填入） |
| Q (17) | 领款人签字 | 留空 |
| R (18) | 备注 | salary_df['备注']（非空时填入） |

**格式复制**: 列宽、字体、对齐方式、边框、合并单元格全部从模板 Sheet 复制。

### 8. `_update_annual_summary`

```python
def _update_annual_summary(
    wb: Workbook,
    sheet_name: str,
    salary_df: pd.DataFrame,
    start_date: tuple
)
```

> 内部函数，由 `generate_ledger_sheet` 自动调用。

**功能**: 将工资数据回写到 `年度工资汇总台账` Sheet。

**月份→列映射规则**: `N月工资 = Col(8 + 2*N)`

| 月份 | 工资列 | 代付列 |
|------|--------|--------|
| 1月 | Col J (10) | Col K (11) |
| 2月 | Col L (12) | Col M (13) |
| 3月 | Col N (14) | Col O (15) |
| 4月 | Col P (16) | Col Q (17) |
| ... | ... | ... |
| 12月 | Col AG (33) | Col AH (34) |

**确定写入列**: 按起始月份。如 `3月11日-4月10日` 起始月为3月 → 写入 Col N（3月工资列）。

**处理逻辑**:
1. **已有人员**: 按姓名匹配，写入跨 Sheet 公式引用 `='3月11日-4月10日工资表'!J{行号}`
2. **新增人员**: 插入在合计行与总计行之间（合计行位置不变），仅将总计行下移
3. **合计行**: 位置不变，所有列（Col E ~ Col AG）的 SUM 公式更新为覆盖全部数据行（包含新增行）

**年度汇总表插入位置示意**:

```
原始结构:
  Row 4~173   数据行（已有人员）
  Row 174     合计
  Row 175     总计

更新后:
  Row 4~173   数据行（已有人员，月份列已更新）
  Row 174     合计（位置不变，SUM 范围已更新）
  Row 175~N   新增人员（插入在合计与总计之间）
  Row N+1     总计（下移到新位置）
```

```python
def generate_report_format(

```

**功能**: 生成上报格式 Excel 文件（花名册 + 考勤表两个 Sheet）。

**输入**:

| `daily_df` | `DataFrame` | 每日考勤明细 |

**输出文件结构**:

#### Sheet 1: `花名册(N月)`

| Row | 内容 |
|-----|------|
| Row 1 | 标题（A1:H1 合并） |
| Row 2 | 项目名称 |
| Row 3 | 分包单位 + 年月 |
| Row 4 | 空 |
| Row 5 | 表头：编号/姓名/性别/工种(或岗位)/家庭地址/身份证号/联系电话/劳动合同编号 |
| Row 6+ | 出勤人员数据（含从花名册读取的完整信息） |

| Row | 内容 |
|-----|------|
| Row 1 | 标题 |

跨月日期处理：
- 自动识别日期范围（如 3/11~4/10）
- 月份1: `range(11, 月末+1)` → 月份2: `range(1, 结束日+1)`

## 计算规则详解

### 工时取整

结算模式下（`for_settlement=True`），工时按半小时向下取整：

```
hours = int(hours * 2) / 2

7.24h → 7.0h
7.25h → 7.0h
7.49h → 7.5h
7.50h → 7.5h
7.74h → 7.5h
7.75h → 7.5h
8.00h → 8.0h
```

### 午休扣除

工时计算中自动扣除休息时间段（默认 12:00-13:00），仅当打卡区间实际经过休息窗口时才扣除交集部分（如下午班 13:00-23:00 不经过休息窗口则不扣除）。休息时间段可通过配置调整。

### 异常打卡

- 单日仅1次打卡 → 标记异常，工时记0，不计入出勤工日
- 单日0次有效打卡 → 标记异常
- 单日>2次打卡 → 取最早和最晚，正常计算，备注中列出所有打卡时间

## 异常处理

系统对以下异常情况有明确处理策略：

| 异常场景 | 处理方式 | salary_df 备注 |
|----------|----------|----------------|
| 考勤中有但花名册无此人 | 保留考勤，工资全为0 | `花名册中无此人` |
| 工种在排除列表中 | 保留考勤，工资全为0 | `排除工种(管理)` |
| 工日工资为"15000元/月" | 保留考勤，工资全为0 | `月薪制(15000元/月)，需人工核算` |
| 工日工资为0 | 保留考勤，工资全为0 | `工日工资为0` |
| 工资标准异常 | 保留考勤，工资全为0 | `工资标准异常(XXX)` |
| 单日仅一次打卡 | 不计入出勤工日，记录到 daily_df | `异常:单日仅一次打卡` |
